# 🤖 Automatización de Contenidos con IA (CrewAI/Groq & Make.com)

¡Bienvenido a mi portafolio! Este proyecto demuestra cómo integrar **Motores de Inteligencia Artificial de Alta Velocidad** con herramientas visuales y plataformas No-Code para automatizar procesos de negocio reales.

## 🚀 ¿Qué resuelve este software?
Este sistema simula una tripulación de agentes autónomos que trabajan en paralelo:
1. **Agente Investigador:** Analiza a fondo los dolores de cabeza y necesidades de un nicho de mercado específico.
2. **Agente Copywriter:** Toma los datos de la investigación y redacta una propuesta comercial persuasiva lista para enviar por WhatsApp o Email.
3. **Conector Visual:** Envía el resultado final de forma automática a plataformas visuales como **Make.com**, **Airtable** o **Google Sheets** mediante webhooks seguros.

## 🛠️ Tecnologías Utilizadas
* **Backend de IA:** Python, API de Groq, Modelos de código abierto (Llama 3.1).
* **Entorno de Pruebas:** Google Colab.
* **Integración No-Code:** Make.com (Webhooks nativos).
